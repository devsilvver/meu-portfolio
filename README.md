### ✨ Funcionalidades

* **👋 Apresentação Pessoal:** Seção "Hero" impactante e biografia profissional.
* **🚀 Vitrine de Projetos:** Grid interativo exibindo os principais trabalhos com descrição, tecnologias usadas e links externos.
* **📱 Design Totalmente Responsivo:** Layout fluido adaptável para Desktop, Tablet e Mobile utilizando CSS moderno (Flexbox, Grid e Variáveis).
* **💬 Conexão Direta:** Botões de ação rápida para contato via **WhatsApp** e redes sociais.
* **🎨 UI/UX Imersiva:** Uso de fontes modernas (Poppins) e paleta de cores consistente (Dark Mode).

### 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as ferramentas mais ágeis do mercado:

* **[React 19](https://react.dev/)** - Biblioteca para construção da interface.
* **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática para código mais seguro e escalável.
* **[Vite](https://vitejs.dev/)** - Build tool de próxima geração (extremamente rápido).
* **[CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)** - Estilização pura com variáveis (`var(--color)`) e animações.
* **[FontAwesome](https://fontawesome.com/)** - Biblioteca de ícones vetoriais.

### 🚀 Como rodar o projeto

#### 1. Clone o repositório
```bash
git clone [https://github.com/devsilvver/meu-portfolio.git](https://github.com/devsilvver/meu-portfolio.git)
cd meu-portfolio
```

#### 2. Instale as dependências
```bash
npm install
```

#### 3. Execute o projeto
```bash
npm run dev
```
O portfólio estará disponível em `http://localhost:3000` (ou a porta indicada pelo Vite).
